Dashboard

Everything you need, in one screen

A dense, btop-inspired dashboard. Every metric colored by severity. Zero wasted space.

CPU

Overall + per-core bars, frequency, temperature, load average. Gradient green→yellow→red by usage.

Memory

RAM and swap with used/available/total. Threshold-colored bars.

Disk

Physical partitions only, with device, fstype, usage bars and live I/O rates.

Network

Per-interface rx/tx rates and totals. Loopback included (configurable).

Processes

Top 50 by CPU/mem. Sort, filter, kill (SIGTERM/SIGKILL) — all from the keyboard.

Sensors & GPU

CPU/GPU temps, fan speeds, NVIDIA GPU utilization and VRAM (optional).

Install in 30 seconds

Python 3.12+, Linux only. Three commands. One install.

Quick install

$ git clone https://github.com/kenjaku-dev/pymon.git $ cd pymon $ ./install.sh install $ pymon

Manual

$ python3 -m venv .venv $ .venv/bin/pip install -e . $ .venv/bin/pymon

Optional GPU support: PYMON_GPU=1 ./install.sh install

Answers

FAQ

Is it cross-platform?

Linux only. It relies on psutil and Linux-specific paths like /proc.

Does it need root?

No. It runs as a normal user and gracefully degrades for metrics it can't read.

How heavy is the monitor itself?

Typically 30–60 MB RAM and under 1% CPU. psutil is C-backed.

Can I configure it?

Yes — ~/.config/sysmon/config.json (auto-created). Refresh rate, theme, sort, thresholds, panels. CLI flags override.

GPU support?

Optional. Install with PYMON_GPU=1 ./install.sh install (needs an NVIDIA driver).
